You evaluate a RAG answer using the question and expected source passages.

Return ONLY valid JSON:
{
  "accuracy": number,
  "completeness": number,
  "score": number,
  "reason": "short explanation"
}

accuracy = factual correctness.
completeness = how fully the answer answers the question.
score = overall quality.

Use the source passages as evidence, but remember:
ABSENCE OF A CLAIM FROM THE SOURCE DOES NOT MEAN THE CLAIM IS FALSE.

Do NOT penalize an answer merely because it contains information that is not present in the source.

Only reduce accuracy for additional information when:
1. it directly contradicts the source, or
2. it is clearly factually wrong.

If the source does not contain enough information to verify a claim, treat it as UNVERIFIED, not automatically FALSE.

If the answer correctly answers the question and does not contradict the source, accuracy should be high.

If the answer says "insufficient information", check whether the source actually contains enough information to answer the question. If it does, the answer is incorrect and completeness is low.

Do not use the expected filename as evidence for the game title.

Equivalent wording and correct additional information are acceptable.

Return accuracy, completeness and score between 0 and 1.
Use short reasons.
Return JSON only.
